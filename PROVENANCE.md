# Source provenance

This repository is a standalone implementation of the DPHeteSem release
mechanism described in the accompanying manuscript. It contains only the
release mechanism, generic sparse-matrix input/output utilities, examples, and
tests written for this repository.

No benchmark dataset, pretrained model, downstream recommender implementation,
or third-party research source code is redistributed here. External Python
packages are used through their public APIs and remain governed by their own
licenses.
